# HGSOC-NK-Stage-Based-Drug-Repurposing-scRNA-Seq-Analysis
Single-cell and pseudobulk transcriptomic analysis of NK-associated populations in high-grade serous ovarian cancer (HGSOC), integrating stage-associated pathway analysis, Connectivity Map-based drug prioritization, and drug annotation using DGIdb and DrugBank. Presented at the 3rd International Congress of Cancer Genomics (2026).
